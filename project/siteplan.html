Inside the Atom

Website Project Site Plan

Site Name

Inside the Atom

This name was chosen because it clearly represents the purpose of the website: exploring the internal structure of atoms and learning about the particles that make up matter.

Site Purpose

The purpose of Inside the Atom is to provide an interactive and easy-to-understand introduction to atomic structure. The site will explain atoms, protons, neutrons, electrons, elements, and atomic numbers. It will also help visitors understand how changing the number of subatomic particles can affect an atom.

Scenarios

  • What are atoms made of, and what roles do protons, neutrons, and electrons have?
  • How does changing the number of protons, neutrons, or electrons affect an atom?

Typography

Orbitron

Orbitron will be used for the website title and major headings to create a scientific and futuristic appearance.

Roboto

Roboto will be used for paragraphs, navigation, buttons, forms, and other general website content because it is clear and easy to read.
